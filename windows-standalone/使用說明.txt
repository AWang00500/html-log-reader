暖析日誌 — Windows 單一檔案離線版使用說明
========================================

1. 執行方式
   本資料夾內的 `index.html` 已將所有 React、Tailwind CSS、圖示與日誌診斷邏輯完整封裝於單一檔案中。
   您可以直接將 `index.html` 複製到 Windows 電腦的任何位置（例如桌面），並使用 Google Chrome（或 Microsoft Edge）直接雙擊開啟（`file://` 模式），無需安裝 Node.js、npm 或啟動本機伺服器。

2. 離線與線上差異說明
   - 日誌上傳（.LOG / .TXT 拖曳與選取）、四分類橫向頁籤（成功 / 失敗 / 警告 / 其他）、失敗與警告折疊診斷（推測原因與檢查檔案建議）、關鍵字搜尋、底部統計與下載診斷報告（.txt）：皆為純前端運算，可 100% 離線使用。
   - 字型載入：`index.html` 保留了 Google Fonts（Plus Jakarta Sans、Noto Sans TC、JetBrains Mono）的線上引用。若在有網路的環境開啟會自動載入網頁字型；若在完全無網路環境開啟，瀏覽器會自動降級使用系統內建無襯線與等寬字體，不影響任何功能與排版。

3. 如何重新建置此單一檔案版本
   在原始專案根目錄執行：
   NODE_ENV=production npx vite build --config vite.standalone.config.ts
